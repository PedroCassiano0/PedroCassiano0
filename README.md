## 🙋 Sobre mim

Estou no início da minha transição de carreira para a área de tecnologia, com o apoio da graduação em **Engenharia de Software**.

Ainda estou construindo minha base e é exatamente isso que você vai encontrar aqui: **código real de quem está aprendendo de verdade**, desde os primeiros exercícios de HTML até os projetos que vêm pela frente.
